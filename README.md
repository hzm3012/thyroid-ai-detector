# ThyroCheck AI

A responsive educational website demonstrating how an AI/ML-style thyroid screening interface can work.

## Features
- TSH, T3 and T4 input form
- Additional medication/history indicators
- Interactive risk estimate
- Responsive modern UI
- Clear medical-use disclaimer
- Model-ready JavaScript architecture

## Run
Open `index.html` in a browser.

## GitHub Pages
In GitHub: **Settings → Pages → Deploy from branch → main → / (root)**, then save. GitHub will provide the public Pages URL after deployment.

## Important
The current prediction is a transparent demonstration scoring function, **not a clinically validated AI model and not a medical diagnosis**. For a real research project, replace the scoring function with a properly trained and validated model using an appropriate dataset, documented preprocessing, evaluation metrics, and clinical oversight.
